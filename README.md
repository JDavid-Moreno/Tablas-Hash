# Tablas-Hash-y-Conjuntos-disyuntos
Este repositorio abarca una guía técnica sobre tablas hash y funciones de dispersión, abordando los mecanismos de resolución de colisiones, cuándo elegirlas para lograr búsquedas en tiempo constante, asi como, sobre Conjuntos Disyuntos, detallando sus optimizaciones por rango y compresión de caminos y ejemplos en código de ambos.
